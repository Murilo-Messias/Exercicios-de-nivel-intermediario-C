# Exercícios de nível intermediário
1.Média ponderada com validação. Leia três notas e seus respectivos pesos (2, 3 e 5). Calcule a média ponderada e exiba a situação (Aprovado se média ≥ 6, Exame se entre 4 e 6, Reprovado se menor). Se algum peso for digitado como 0, exiba uma mensagem de erro antes de calcular.

2.Maior, menor e média de N números. Peça ao usuário quantos números ele quer digitar (N), leia-os um a um em um for, e ao final mostre o maior valor, o menor valor e a média de todos, sem usar vetor (apenas variáveis acumuladoras).

3.Contagem de aprovados e reprovados. Leia as notas de 10 alunos usando for, calcule a média de cada um e, ao final, informe quantos foram aprovados, quantos ficaram de exame e quantos foram reprovados (três contadores).

4.Classificação de triângulo. Leia três valores representando os lados de um triângulo. Usando if/else if e operadores lógicos, informe se é equilátero, isósceles, escaleno ou se os valores não formam um triângulo válido (a soma de dois lados deve ser maior que o terceiro).

5.Tabuada até o usuário decidir parar. Peça um número, mostre a tabuada de 1 a 10 com for e, ao final, pergunte "Deseja ver outra tabuada? (1-Sim / 0-Não)". Use while para repetir todo o processo até o usuário escolher sair.

6.Contador de vogais e consoantes. Leia uma palavra com scanf("%49s", ...), percorra o vetor de char caractere por caractere com for (usando o índice até encontrar \0), e conte quantas vogais e quantas consoantes ela contém.

7.Verificador de número primo. Leia um número inteiro positivo e, usando for e o operador %, verifique se ele é primo (não é divisível por nenhum número entre 2 e ele mesmo, exceto por 1 e por ele próprio).

8.Menu de calculadora com repetição. Monte um menu com printf mostrando as opções 1-Soma, 2-Subtração, 3-Multiplicação, 4-Divisão, 5-Sair. Use while para repetir o menu, scanf para ler a opção, e if/else if para executar a operação escolhida, tratando divisão por zero.

9.Sequência de Fibonacci. Peça quantos termos o usuário quer ver (N) e, usando for e três variáveis inteiras (sem vetor), calcule e mostre os N primeiros termos da sequência de Fibonacci (0, 1, 1, 2, 3, 5, 8...).

10.Validação de faixa com laço de repetição. Peça ao usuário para digitar um número entre 1 e 100. Use while para repetir a pergunta até que um valor válido seja digitado (rejeitando valores fora da faixa com uma mensagem de erro), e ao final exiba quantas tentativas foram necessárias.
